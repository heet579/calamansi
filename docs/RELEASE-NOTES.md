**Calamansi is a local file converter for Windows.** Select files, start dragging, hold **Shift**, and drop them on a format.

### Get started
1. Download **Calamansi-…-windows-x64.zip** below and unzip it.
2. Double-click **Calamansi.exe**. You don't need an installer or anything else, and nothing is downloaded.
3. Right-click the tray icon and choose **Run self-test** to check every conversion on your PC.

### What it does
- **Shift + drag:** convert images, PDFs (to images, Word or text), Word/Excel/PowerPoint (to PDF), subtitles, audio and video
- **Ctrl + Shift + drag:** tools such as Make PDF, Collage, Merge, Split, Resize, Compress, Rotate, Flip, Grayscale, Duplicate, Copy path and SHA-256
- **Right-click → Send to → Calamansi** (turn it on in the tray menu)
- Originals are never changed or overwritten. Everything stays on your PC.

Optional: FFmpeg (`winget install ffmpeg`) for audio and video; Microsoft Office or LibreOffice for Word/Excel/PowerPoint.

This is an early preview, and the app is not code-signed yet. If Windows SmartScreen warns you, click **More info → Run anyway**. Please report problems in Issues and attach `%LOCALAPPDATA%\Calamansi\calamansi.log`.
